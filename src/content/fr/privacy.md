# Politique de confidentialité

Veuillez noter que nous, TransDB.com, n'avons aucun contrôle sur le contenu ou les pratiques de confidentialité des sites web liés à notre site.
Ainsi, cette politique de confidentialité se limite aux sous-pages qui se trouvent directement sur notre domaine (TransDB.com).

## Cloudflare

Nous utilisons [Cloudflare](https://www.cloudflare.com/) comme protection DDoS.

Pour rendre cela possible, toutes les requêtes vers notre site web passent par Cloudflare.
Cloudflare enregistre des données dans ce processus pour vérifier si une attaque se produit.
Ces données comprennent, sans s'y limiter :

- Votre adresse IP
- Le type de votre navigateur et de votre appareil

Vous pouvez découvrir exactement quelles données sont collectées et stockées dans la [« Politique de confidentialité » de Cloudflare](https://www.cloudflare.com/de-de/privacypolicy/).

Notez également la [conformité RGPD de Cloudflare](https://www.cloudflare.com/de-de/gdpr/introduction/).

## Statistiques d'utilisation

Nous utilisons [Ackee](https://ackee.electerious.com/) pour des statistiques d'utilisation anonymes.
Ce logiciel s'exécute directement sur notre serveur et n'est pas hébergé en externe.

Ackee stocke notamment les données suivantes :

- Le navigateur que vous utilisez
- Le lien de référence (d'où vous venez sur notre site)
- Le type de votre appareil

Les données stockées par Ackee ne sont pas personnellement identifiables.  
Elles sont utilisées uniquement pour rendre notre site plus convivial.

Aucune adresse IP n'est stockée.

## Journalisation

En cas de dysfonctionnement, la journalisation des erreurs de notre serveur peut temporairement stocker l'adresse IP, le type de navigateur et le type d'appareil des visiteurs.
Ces données ne sont pas rendues publiques.

Elles seront utilisées uniquement pour mieux comprendre comment le dysfonctionnement s'est produit et seront supprimées dès que le dysfonctionnement aura été corrigé.

## Cookies

TransDB.de n'utilise pas de cookies de suivi et n'utilise pas de scripts externes utilisant des cookies de suivi.

## Google Fonts

Les polices utilisées par notre site web sont open source et proviennent à l'origine de Google Fonts.
Nous n'utilisons pas l'API Google Fonts, mais hébergeons les données nous-mêmes.
Ainsi, aucune connexion n'est établie avec les serveurs Google et aucune donnée n'est transmise à Google.

## Localisation

TransDB.de utilise une recherche de localisation, où vous pouvez soit saisir votre position manuellement, soit laisser le navigateur capturer vos coordonnées.
Cette fonctionnalité est optionnelle et ne sera pas exécutée sans le consentement de l'utilisateur.

La recherche de localisation est effectuée par notre propre serveur. Votre position ne sera pas partagée avec des tiers.
Notre recherche de localisation ne stocke pas la position recherchée.
